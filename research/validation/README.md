# حزمة التحقق العربية لبصيرة — الإصدار 1

هذه الحزمة تنشئ بنية تحقق قابلة لإعادة التشغيل. لا تحتوي على تسجيلات أطفال حقيقية أو نتائج دقة مختلقة؛ البيانات الاصطناعية مخصصة لاختبار الكود فقط.

## الأهداف
1. جودة التسجيل: هل كانت الصورة/الصوت صالحين تقنيًا؟
2. أداء الأداة: ما خطأ التعرف الصوتي أو تقدير النظر مقارنة بمرجع معلّم؟
3. المراجعة التربوية: ما الذي صنّفه مراجع بشري؟ لا يُستنتج التشخيص آليًا.

## الملفات
- `protocol.md`: بروتوكول جمع البيانات والمراجعة والتقسيم.
- `schema.json`: مخطط سجل القياس.
- `scripts/evaluate_validation.py`: يحسب WER/CER وخطأ إحداثيات النظر.
- `fixtures/synthetic_example.jsonl`: بيانات اصطناعية لاختبار التشغيل.

## التشغيل
يتطلب Python 3.10+ ولا يحتاج حزمًا خارجية:

```bash
python research/validation/scripts/evaluate_validation.py research/validation/fixtures/synthetic_example.jsonl
```

نتائج fixture الاصطناعي ليست خط أساس للأداء. خزّن البيانات الحقيقية خارج Git ومستودعات عامة، ولا تُحلّل بيانات حقيقية إلا بعد توثيق الموافقة.

## تفسير النتائج
- WER/CER تستخدمان تطبيعًا بسيطًا يفصل الكلمات بالمسافات ويحافظ على الحروف العربية والتشكيل.
- الخطأ مقابل موضع الهدف ليس دقة نظر مرجعية؛ موضع الهدف لا يثبت أين نظر الشخص فعليًا.
- لا تقبل تقرير دقة دون حجم العينة، وعدد المشاركين والجلسات، وتقسيم الاختبار، والمفقودات، والمقاييس لكل مشارك.
- يجب فصل المشاركين بين التطوير والاختبار عند تقييم التعميم على أطفال جدد.
- هذه الحزمة لا تشخّص عسر القراءة أو عسر الحساب ولا تثبت صلاحية سريرية.
