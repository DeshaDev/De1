# بصيرة (Baseera)
## منصة عربية لاستكشاف مهارات القراءة والحساب ومتابعة التعلّم

**بصيرة** نموذج أولي لمنصة تعليمية عربية تساعد المدارس والأسر على تقديم أنشطة قراءة وفهم وحساب، وتوثيق أداء الطالب داخل النشاط، واختيار الخطوة التعليمية التالية بمساندة المعلّم.

> **حدود الاستخدام:** بصيرة ليست أداة تشخيص طبي أو نفسي، ولا اختبارًا معياريًا معتمدًا لعسر القراءة أو عسر الحساب. النتائج الحالية وصفية واستكشافية ضمن الأنشطة المعروضة. لا تُستخدم لاتخاذ قرار عالي الأثر بشأن طفل دون تقييم مناسب من مختص مؤهل.

## ما الذي يتضمنه النموذج الحالي؟

- **القراءة والفهم:** نصوص عربية متدرجة، مؤقت جلسة، وأسئلة فهم مرتبطة بالنص.
- **القراءة الجهرية الاختيارية:** قد يستخدم هذا المسار الميكروفون والتعرّف الصوتي في المتصفح. المخرجات الآلية قابلة للخطأ، ويجب أن يراجع المعلّم الكلمات قبل اعتماد مؤشر الكلمات الصحيحة في الدقيقة (WCPM).
- **الحساب والحس العددي:** أنشطة قصيرة للأعداد وخط الأعداد والتمييز الكمي، تعرض أداء الطالب في المهمة الحالية ولا تُنتج معيارًا سكانيًا أو تشخيصًا.
- **القارئ الميسّر:** خيارات عرض تساعد على تجربة قراءة النصوص والاستماع إلى نطق الكلمات عند دعم المتصفح.
- **التدريب وملخصات التعلّم:** أنشطة مساندة وملخصات تعتمد على البيانات المتاحة ومراجعة المعلّم.
- **مساحة المعلّم:** صلاحيات بحسب المؤسسة، مع دعم حفظ السجلات عندما تكون متطلبات الخادم والتشفير والمصادقة مضبوطة.

## الخصوصية: لا كاميرا ولا تتبّع للعين

لا تستخدم بصيرة الكاميرا أو تتبّع العين أو الصور أو الفيديو. لا تحتاج القراءة الصامتة أو أنشطة الحساب والقارئ الميسّر إلى تشغيل الميكروفون. قد يطلب المتصفح الميكروفون عند اختيار القراءة الجهرية فقط.

قد يختلف مكان معالجة الصوت بحسب المتصفح أو مزود خدمة التعرف الصوتي. لا تفترض أن الصوت يُعالج محليًا بالكامل. استخدم بيانات اصطناعية أثناء التجربة، ولا تدخل بيانات أطفال حقيقية حتى تكتمل مراجعة الخصوصية، والموافقات، ومزودي الخدمات، ومواقع معالجة البيانات.

**الإطار القانوني المستهدف:** دولة قطر، بما في ذلك قانون رقم (13) لسنة 2016 بشأن حماية خصوصية البيانات الشخصية. تُعد بيانات الأطفال من البيانات ذات الطبيعة الخاصة في القانون القطري، وقد تتطلب معالجة هذه البيانات تصريحًا من الجهة المختصة، كما ترد التزامات خاصة للمواقع الموجهة للأطفال. وجود صفحة سياسة أو خانة موافقة لا يثبت وحده اكتمال الامتثال. يجب أن يراجع مشغّل الخدمة والمؤسسة المتطلبات والتصاريح والأدوار الفعلية مع مختص قبل الإطلاق الإنتاجي.

## الدقة العلمية وما لا نزعم إثباته

- معدل الكلمات في الدقيقة (WPM) المحسوب من زمن إكمال النص يفترض أن النص قُرئ كاملًا؛ لا يثبت وحده دقة القراءة أو أن كل كلمة قُرئت.
- لا يساوي WPM في القراءة الصامتة معدل الكلمات الصحيحة في القراءة الجهرية (WCPM).
- لا تُعرض مخرجات التعرّف الصوتي بوصفها حقيقة مرجعية. يجب مراجعتها مقابل النص المرجعي، مع توثيق الأخطاء والتباينات اللهجية.
- نتائج الأسئلة والمهام الحسابية تصف أداءً في تلك المهمة فقط. لم تُثبت بعد صلاحية أي حدّ قرار أو معيار معياري في بصيرة على عينة عربية مستقلة.
- لا تُقدَّم نتائج بحثية على أنها تحقق من المنتج نفسه. صلاحية الأداة المستخدمة في دراسة سابقة لا تنتقل تلقائيًا إلى هذا التطبيق أو إلى مستخدمين في سياق مختلف.

## مراجع يمكن التحقق منها

1. **Alqahtani, Saeed Saad (2024).** “Validating Curriculum-Based Measurement Oral Reading Fluency (CBM ORF) Applicability To Evaluate Arabic Readers’ Performance.” *Ijaz Arabi Journal of Arabic Learning, 7(2).*  
   [المقال وبيانات النشر](https://doi.org/10.18860/ijazarabi.v7i2.26356). اختبرت الدراسة أشكالًا من CBM-ORF على عينة من 414 طالبًا وقدّمت معايير أولية لسياقها؛ ليست اعتمادًا لمقاييس بصيرة.

2. **El Fiky, Yomna Hassan (2016).** “Modification and Standardization of Egyptian dyslexia screening test for children.”  
   [سجل جامعة عين شمس](https://research.asu.edu.eg/handle/12345678/51928). الدراسة تخص اختبار MADST وسياق تقنينه المصري، ولا تُعد معيارًا عربيًا عامًا أو تحققًا من بصيرة.

3. **Arabic Little STT: Arabic Children Speech Recognition Dataset (2025).**  
   [arXiv:2510.23319](https://arxiv.org/abs/2510.23319). تضم مجموعة البيانات 355 عبارة من 288 طفلًا ناطقًا بلهجة شامية (6–13 سنة)، واختبرت الدراسة ثمانية نماذج Whisper. أفضل WER مذكور هو 0.66 لـ Whisper Large-v3 ضمن هذه المجموعة؛ لا يمثل هذا الرقم دقة التعرف الصوتي داخل متصفح بصيرة ولا جميع اللهجات العربية.

4. **Siegler, R. S., & Booth, J. L. (2004).** “Development of numerical estimation in young children.” *Child Development, 75(2), 428–444.*  
   [DOI: 10.1111/j.1467-8624.2004.00684.x](https://doi.org/10.1111/j.1467-8624.2004.00684.x). تبحث الدراسة تطور تقدير الأعداد على خط الأعداد؛ ولا تُثبت وحدها صلاحية اختبار بصيرة أو تشخيص عسر الحساب.

5. **Zerouali et al. (2026).** “A Dyscalculia Diagnostic Battery for Moroccan Children: Development and Preliminary Validity Evidence.”  
   [DOI: 10.1177/07342829261484042](https://doi.org/10.1177/07342829261484042). تقدم الدراسة أدلة أولية على بطارية خاصة بسياق مغربي (79 بندًا وتسعة مجالات). لا تعني نتائجها أن بصيرة قد تم التحقق منها، ولا أنها معيار قطري أو عربي عام.

هذه المراجع خلفية لتصميم الأنشطة والأسئلة البحثية فقط، وليست ادعاءً باعتماد المنصة علميًا أو سريريًا.

## التطوير والتشغيل

يتطلب المشروع Node.js حديثًا وnpm.

```bash
npm install --legacy-peer-deps
npm run dev
```

فحوص المشروع:

```bash
npm run lint
npm test
npm run build
```

تستخدم ميزات الخادم إعدادات بيئية للمصادقة ومفتاح تشفير التخزين. لا تنشر الخدمة ولا تحفظ سجلات حقيقية ما لم تُضبط هذه القيم بطريقة آمنة في بيئة النشر. راجع `.env.example` وإعدادات الاستضافة، ولا تضف الأسرار إلى المستودع.

## حالة المشروع

بصيرة في مرحلة النموذج الأولي والتحقق. لا نعلن وجود اعتماد سريري، أو تحقق مستقل من دقة المؤشرات، أو امتثال قانوني نهائي، أو نتائج تجارية/إيرادية ما لم توثّق هذه النتائج بأدلة منفصلة وقابلة للمراجعة.


## Deployment and repository rights

The production build generates a browser bundle in `dist/` and a bundled Node.js server entry point at `server.js`. Run `npm run build` before `npm start`, or use the supplied multi-stage Dockerfile. Production deployment must configure unique access-code, session-signing, and storage-encryption secrets.
