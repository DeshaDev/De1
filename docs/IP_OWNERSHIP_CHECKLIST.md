# قائمة تدقيق ملكية الملكية الفكرية قبل التمويل

هذه القائمة مخصصة لاجتماعات المستثمرين وإجراءات الفحص النافي للجهالة. وجود ملف `LICENSE` في المستودع يحدد موقف إعادة الاستخدام، لكنه **لا يثبت وحده أن الشركة تملك حقوق المؤلف في كل ملف**. لا ترفع عقودًا موقعة أو بيانات شخصية إلى مستودع عام.

## المطلوب استكماله وتوثيقه

- [ ] تحديد المالك القانوني الحالي للكود: المؤسس شخصيًا أم الشركة، مع توثيق الاسم القانوني الصحيح.
- [ ] مراجعة سجل Git وتحديد جميع المساهمين الذين كتبوا أو راجعوا أو سلّموا كودًا أو تصميمات أو محتوى.
- [ ] الحصول على تنازل مكتوب عن حقوق الملكية الفكرية أو اتفاقية تطوير واضحة من كل موظف أو متعاقد أو مساهم ذي صلة، بحسب القانون والعقد المنطبقين.
- [ ] إذا كان الكود مملوكًا للمؤسس شخصيًا، تنفيذ نقل موثق إلى الكيان القانوني الذي سيطلب التمويل.
- [ ] فحص الاعتماديات المباشرة والمتعدية في `package.json` و`package-lock.json`، وتوثيق التراخيص والالتزامات ذات الصلة.
- [ ] مراجعة أصول الخطوط والأيقونات والصور والمحتوى التعليمي ومجموعات البيانات وأي مواد مقتبسة، والتأكد من وجود حق استخدام مناسب.
- [ ] تحديد مالك حسابات النطاق والاستضافة ومفاتيح الخدمات والبنية السحابية، ونقل السيطرة إلى الشركة عند اللزوم.
- [ ] حفظ العقود والإقرارات وسجل مراجعة التراخيص خارج المستودع العام، مع تقييد الوصول إليها.

## صياغة آمنة لحالة المشروع الحالية

لا تفترض أن الشركة تملك جميع الحقوق قبل استكمال البنود ذات الصلة. عند سؤال المستثمر عن الملكية، اعرض المستندات التي جرى التحقق منها فقط، واذكر بوضوح أي تنازل أو مراجعة تراخيص ما زال قيد الإكمال. هذه القائمة ليست رأيًا قانونيًا؛ ينبغي مراجعة المستندات مع محامٍ مختص قبل إغلاق جولة الاستثمار.
