# التشغيل السريع — بصيرة

بصيرة نموذج أولي تعليمي باللغة العربية لاستكشاف مهارات القراءة والفهم والحساب ومتابعة الأداء داخل الأنشطة.

## المتطلبات

- إصدار حديث من Node.js يدعمه Vite 8.
- npm.
- إعداد بيئة الخادم قبل تفعيل تسجيل الدخول أو حفظ سجلات الطلاب.

## التثبيت والتشغيل

```bash
npm install --legacy-peer-deps
npm run dev
```

## التحقق قبل الدمج أو النشر

```bash
npm run lint
npm test
npm run build
```

## ما الذي يستخدمه المنتج؟

- القراءة الصامتة وأسئلة الفهم: لا تحتاج إلى إذن وسائط.
- الحساب والقارئ الميسّر والتدريب: لا تحتاج إلى الكاميرا أو الميكروفون.
- القراءة الجهرية: اختيارية وتطلب الميكروفون فقط عند اختيارها. قد يتولى المتصفح أو مزوّد التعرف الصوتي معالجة الصوت؛ لا تفترض أن المعالجة محلية بالكامل.

**تم إلغاء الكاميرا وتتبع العين من المنتج.** لا تستخدم هذه الميزات، ولا تتوفر شاشات المعايرة القديمة في الواجهة المنشورة.

## إعداد الخادم

راجع `.env.example` واضبط الأسرار خارج المستودع في بيئة الاستضافة. يحتاج حفظ سجلات الطلاب إلى إعداد المصادقة ومفتاح تشفير التخزين وبيانات اعتماد المؤسسة. لا تُدخل بيانات أطفال حقيقية قبل التحقق من إعدادات النشر والموافقات ومتطلبات دولة قطر ومزودي الخدمات.

## حدود النتائج

المقاييس الحالية وصفية ضمن النشاط وليست اختبارًا معياريًا أو تشخيصًا لعسر القراءة أو عسر الحساب. زمن إكمال النص لا يثبت وحده أن كل كلمة قُرئت أو قُرئت بشكل صحيح. أي مخرجات صوتية آلية قابلة للخطأ وتحتاج إلى مراجعة بشرية مناسبة.
